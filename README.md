Pigeon Pitch, One Line — the elevator pitch a city pigeon gives investors for its startup: every statue in the city, turned into a co-working space whose tenants pay in exposure.

> I turned every statue in the city into a co-working space: 40,000 members, zero rent, and they all pay in exposure. I'm raising a seed round to buy more statues.

## Run it

```sh
node main.ts
```

This writes the one-line pitch (161 characters) to `entry.txt` under `$OUTPUT_DIR` (or `$MAKEFUN_OUTPUT_DIR`, default `/output`).
